# 2026-VK-EDU-Web-11-Petrukhina-A

Учебный проект по верстке сайта вопросов и ответов «Поясняем на котятах».

## Как открыть проект

Проект представляет собой статическую верстку на HTML и CSS.

Чтобы открыть сайт:
1. Перейдите в папку `public`
2. Откройте файл `index.html` в браузере

## Страницы проекта

- `public/index.html` — главная страница со списком вопросов
- `public/question.html` — страница одного вопроса со списком ответов
- `public/ask.html` — страница добавления нового вопроса
- `public/profile.html` — страница профиля / настроек пользователя
- `public/tag.html` — страница вопросов по тегу

## Структура проекта

- `public/` — HTML-страницы
- `public/static/css/` — стили
- `public/static/img/` — изображения, аватары, иконки

## Использованные технологии

- HTML5
- CSS3
